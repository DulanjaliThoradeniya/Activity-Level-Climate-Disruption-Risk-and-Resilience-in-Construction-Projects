# C-RESIST AI
Editable HTML/CSS/JavaScript prototype for climate-shock risk and resilience assessment in construction.

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Edit
- Structure/content: `index.html`
- Design: `style.css`
- Simulation/interactions/animations: `script.js`

## Current demonstrator
Extreme regional flood -> precast supply-chain cascade -> performance loss/recovery -> dynamic risk/resilience -> AI-style interpretation -> counterfactual resilience intervention.
