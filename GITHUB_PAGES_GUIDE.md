# GITHUB PAGES GUIDE
1. Create a GitHub repository.
2. Copy all files in this folder to the repository root.
3. Commit and push.
4. GitHub -> Settings -> Pages.
5. Choose Deploy from a branch -> `main` -> root.
6. Save and wait for deployment.

The required public files are `index.html`, `style.css`, `script.js`, and any files you later add to `assets/`.
