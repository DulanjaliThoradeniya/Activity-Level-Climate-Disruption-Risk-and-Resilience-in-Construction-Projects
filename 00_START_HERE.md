This is the editable static website kit. Open this entire folder in VS Code.

## Main editable files
- `index.html` — webpage structure and text
- `style.css` — colours, typography, layout, responsive design
- `script.js` — animations, sliders, browser-side simulation, charts and counterfactual demo
- `DESIGN.md` — design/research brief
- `CODEX_PROMPTS.md` — prompts you can paste into Codex while editing
