# DESIGN.md — C-RESIST AI

## Purpose
Interactive research prototype for an AI for Sustainable Design assignment.

## Research concept
Extreme climate shock -> cascading construction disruption -> dynamic risk -> resilience trajectory -> AI interpretation -> tipping behaviour -> counterfactual intervention.

## Demonstration case
Extreme regional flood affecting a precast construction supply chain and structural installation process.

## Personality
Technical / rigorous / experimental.

## Visual hierarchy
1. Extreme-shock research question.
2. Construction-system network.
3. Interactive shock controls.
4. Dynamic risk/resilience outputs.
5. AI interpretation and intervention.

## Distinctive design move
The website behaves like a research stress-testing console rather than a generic dashboard or SaaS landing page.

## Constraints
- Plain HTML, CSS and vanilla JavaScript.
- Editable in VS Code.
- No framework required.
- GitHub Pages compatible.
- Never present simulated assumptions as observed empirical facts.
